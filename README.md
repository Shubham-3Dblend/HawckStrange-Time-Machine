# HAWKSTRANGE 👽💻

Welcome to **HAWKSTRANGE** — a futuristic story-based game where you have to save a server from an alien attack.

The aliens have taken control of the server, and now it's your job to find their entry point, solve their security challenges, and take the server back.

---

## 🎮 How to Play

Start the game and follow the story.

You will get different missions and tasks as you move forward.

Your main goal is:

**Find the aliens → Break their security → Restore the server → Save the system**

---

## 👽 The Story

Something strange has entered the system.

An unknown alien signal has been detected, and the server is slowly getting taken over.

You will meet an alien during the game.

The alien will give you messages, clues and challenges.

Pay attention to what it says because some clues can help you complete the tasks.

---

## 💻 What You Have To Do

During the game, you will have to:

- 🔍 Find where the alien entered the server
- 💻 Use the in-game terminal
- 🧩 Solve different puzzles
- 🔐 Break fictional security locks
- 🧠 Decode alien messages
- ⚡ Restore damaged server nodes
- 🛡️ Break through the final firewall
- 💾 Recover the server

You don't need real hacking knowledge.

Everything is part of the game.

---
